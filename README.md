# VOUCCOM Careers

One-page careers site for the VOUCCOM launch team (Lagos). React + TypeScript + Vite.

```bash
npm install
npm run dev      # local dev server
npm run build    # static output in dist/
```

- Roles, apply email and closing date: `src/data/roles.ts`
- Placeholder content is wrapped in `<Dummy>` and shows in pink. Replace it before publishing.
